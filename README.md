### 🏆 Featured Production Systems

#### 🏥 01. [VitalQ | Hospital OPD Priority Queue & CTAS Triage Platform](https://github.com/muxdaslam-sys/VitalQ)
> **Stack:** `Angular Signals` • `ASP.NET Core Web API` • `SignalR WebSockets` • `EF Core` • `SQL Server` • `RxJS`  
> * **10,000+ Concurrency:** Multi-room WebSocket hubs (`Doctor`, `Patient`, `Nurse Station`, `Admin`) with JWT auto-rotation, reducing server polling by 95%.
> * **Clinical Triage Scoring:** Automated Canadian Triage and Acuity Scale (CTAS Levels 1-5) evaluation with dynamic waiting-time aging workers.
> * **Sub-Millisecond Data Seeks:** 23 physical filtered B-Tree indexes delivering `<0.5ms` queries with zero slow table scans.
> * **RxJS Concurrency Mutex:** Deduplicated parallel 401 refresh calls, eliminating session dropouts during network spikes.  
> 
> 🔗 **[Explore VitalQ Repository →](https://github.com/muxdaslam-sys/VitalQ)** • 📄 **[Architecture Deep Dive →](https://github.com/muxdaslam-sys/VitalQ/blob/main/PROJECT_STATE.md)**

<br/>

#### 💼 02. [JobNest | Recruitment Portal & ATS Candidate Pipeline](https://github.com/muxdaslam-sys/JobNest)
> **Stack:** `ASP.NET MVC 5` • `C#` • `Entity Framework 6` • `SQL Server` • `LINQ` • `Razor` • `Bootstrap` • `AJAX`  
> * **Dual-Role Pipelines:** Granular Role-Based Access Control (RBAC) separating Job Seekers from Corporate Employers.
> * **Interactive ATS Workflow:** Instant AJAX candidate progression pipeline (`Applied` ➔ `Shortlisted` ➔ `Interview` ➔ `Hired`).
> * **Hardened Resume Ingestion:** Multi-stage server-side MIME type inspection and randomized naming restricting uploads to 5MB.  
> 
> 🔗 **[Explore JobNest Repository →](https://github.com/muxdaslam-sys/JobNest)**
