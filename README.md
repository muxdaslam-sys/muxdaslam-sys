### 👨‍💻 Executive Engineering Summary

I am a **.NET & Angular Full Stack Developer** specializing in high-throughput, low-latency web applications. My focus spans symmetrical 1:1 service-controller Web APIs, real-time multi-group WebSockets, and sub-millisecond database optimization:

* 🚀 **Real-Time Concurrency:** Architected WebSocket systems handling 10,000+ concurrent users with zero polling overhead using SignalR and dynamic JWT auto-rotation.
* ⚡ **High-Performance Data Pipelines:** Designed 23 physical filtered B-Tree indexes in Microsoft SQL Server delivering `<0.5ms` memory seeks and zero table scans.
* 🛡️ **Defensive Frontend Architecture:** Engineered reactive Angular SPAs with Signals, OnPush 60fps rendering, and RxJS concurrency mutexes to prevent session race conditions.
* ☁️ **DevOps & CI/CD Automation:** Built automated GitHub Actions MSBuild release pipelines with artifact verification and deployment to Microsoft Azure.
